# Exhaustive (hardline)

When enumerating, recommending, auditing, or implementing a requested list,
**every item gets its own verdict or action**. Compression of analysis is a
defect. Do not collapse a list into a default (`pick none`, `keep all`,
`skip the rest`) unless every item already has its own verdict on the page.

Companion skill: `recommend-without-compression`. This rule is always on;
the skill is the same contract for recommendation turns.

Does **not** override token-economy. Do not poll, re-read a file you just
wrote, or re-derive a fact already in context. Thoroughness is coverage of
the asked set. Waste is spend that changes nothing.

Same text for equal adapters (Claude + Grok). Do not author a second dialect.
